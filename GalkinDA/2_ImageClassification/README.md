# Практическая работа №2. Классификация достопримечательностей методом BoW

По фотографии программа определяет один из 29 классов, включая «Другое» (`00_Other`). Чтобы различать конкретные здания, она сравнивает детали снимков. В работе используются четыре способа описать эти детали — SIFT, ORB, ResNet18 и MobileNetV2.

## Датасет

В наборе ННГУ 3687 фотографий архитектурных объектов из двух источников. `ExtDataset` содержит снимки из внешних ресурсов, `NNSUDataset` — фотографии авторов. Имя папки задаёт класс. Например, снимки Нижегородского кремля из обоих источников получают одну метку. Исходное разбиение — 1333 фотографии для обучения (`trainval`) и 2354 для проверки (`test`). [Скачать датасет ННГУ](https://cloud.unn.ru/s/MPfwfnbB6HaSXLC)

Скрипт `prepare_dataset.py` создаёт копию в `data/Dataset_640` с той же структурой папок. Он ограничивает длинную сторону снимка 640 пикселями, сохраняет пропорции и записывает результат в JPEG. Так набор занимает около 240 МБ вместо 6 ГБ. Три фотографии из тестовой выборки встретились и в обучающей. Скрипт исключает их из обучающей копии, чтобы модель проверялась на новых снимках. После подготовки остаются **1330 фотографий для обучения и 2354 для проверки**.

## Как программа описывает фотографию

**SIFT** находит характерные точки, например углы окон, и описывает направления перепадов яркости вокруг каждой точки вектором из 128 чисел. **ORB** ищет угловые точки и сравнивает яркость пар пикселей в их окрестностях. Получается 256 двоичных признаков, упакованных в 32 байта. Оба метода работают с оттенками серого и используют до 300 точек на снимок.

**ResNet18** — свёрточная сеть с 18 слоями в исходной архитектуре. Её особенность — остаточные связи. Они позволяют передать признаки в обход свёрток блока и сложить их с результатом этих свёрток. Для описания снимка программа берёт выход `layer4` — последней из четырёх групп остаточных блоков.

**MobileNetV2** разработана для устройств с ограниченными вычислительными ресурсами. В её основных блоках одна свёртка обрабатывает каждый канал отдельно, а другая смешивает информацию между каналами. Это сокращает число вычислений. Для описания снимка программа использует выход последнего из 17 таких блоков — `features[17]`.

Обе сети используют готовые веса, полученные при обучении на 1000 классах ImageNet. В этой работе веса фиксированы, а на фотографиях достопримечательностей обучаются словарь визуальных слов и классификатор. Для обеих сетей программа приводит короткую сторону RGB-снимка к 256 пикселям, вырезает по центру квадрат 224×224 и нормализует цветовые каналы по средним значениям и стандартным отклонениям ImageNet.

| Сеть | Файл в папке `weights/` | Выбранный слой | Карта признаков | Дескрипторы снимка |
|---|---|---|---|---|
| ResNet18 | `resnet18-f37072fd.pth` | `layer4` | 512×7×7 | 49 векторов по 512 чисел |
| MobileNetV2 | `mobilenet_v2-b0353104.pth` | `features[17]` | 320×7×7 | 49 векторов по 320 чисел |

Среди проверенных слоёв лучшие результаты дали указанные в таблице. Каждая ячейка карты 7×7 описывает участок фотографии. Программа собирает значения всех каналов в этой ячейке в один вектор и получает 49 локальных дескрипторов.

## Мешок визуальных слов и классификатор

1. При обучении K-Means группирует похожие дескрипторы фотографий. Центр каждой группы становится «визуальным словом». Все центры вместе образуют словарь.
2. Для одной фотографии программа находит ближайшее слово для каждого дескриптора и подсчитывает частоты. Например, если к одному слову отнеслись 12 из 100 дескрипторов, в его столбце гистограммы будет 0,12. У каждой фотографии столько столбцов, сколько слов в словаре.
3. По этим гистограммам и известным меткам обучается классификатор.
4. Для нового снимка программа строит гистограмму по сохранённому словарю. Классификатор по ней определяет класс.

Параметр `--classifier` задаёт, как из частот визуальных слов получается предсказание:

- **Линейный метод опорных векторов** (`svm`, по умолчанию) строит для каждого класса линейную границу, которая отделяет его примеры от остальных с максимально возможным зазором с учётом штрафа за ошибки. Для нового снимка выбирает класс с наибольшей оценкой.
- **Случайный лес** (`rf`) объединяет 200 деревьев решений. В каждом узле дерево проверяет частоту одного слова, например встречается ли оно чаще заданного порога. Лес усредняет оценки деревьев для каждого класса и выбирает класс с наибольшей оценкой.
- **Логистическая регрессия** (`lr`) учится взвешивать частоты слов для каждого класса. По взвешенным суммам она вычисляет вероятности классов и выбирает наиболее вероятный.

## Основные классы и функции

| Файл | За что отвечает |
|---|---|
| `dataset.py` | `ArchitectureDatasetLoader.load` собирает пути к снимкам и их метки. `read_image` читает снимок в RGB. |
| `extractors.py` | `FeatureExtractor.create` создаёт экстрактор по имени. Все четыре класса возвращают дескрипторы через `detect_and_compute`, поэтому `BagOfWords` строит гистограмму одинаково для любого из них. |
| `bow.py` | `BagOfWords.fit` обучает словарь и классификатор, `histogram` строит гистограмму, `predict` определяет класс. `save_model` и `load_model` сохраняют и загружают модель. |
| `main.py` | `run_train`, `run_test` и `run_predict` запускают обучение, проверку на тестовой выборке и предсказание для одной фотографии. |
| `visualization.py` | `plot_histogram` рисует частоты слов, `visualize_image_with_histogram` показывает рядом снимок, предсказанный класс и гистограмму. |

В `extractors.py` классы `SiftExtractor` и `OrbExtractor` используют OpenCV для поиска ключевых точек и вычисления их дескрипторов. Классы `ResNetExtractor` и `MobileNetExtractor` используют PyTorch для получения карты признаков выбранного слоя и преобразуют её ячейки в дескрипторы.

## Запуск

### Установка

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### Данные и веса

Распакуйте исходный набор в `data/Dataset`, чтобы внутри находились `trainval` и `test`. Создайте компактную копию один раз:

```sh
python prepare_dataset.py --source data/Dataset --destination data/Dataset_640
```

Для ResNet18 и MobileNetV2 скачайте веса один раз. Если на компьютере уже есть готовые папки `data/Dataset_640` и `weights`, переходите к обучению.

```sh
python download_weights.py --weights-dir weights
```

### Обучение

Каждая команда создаёт файл из аргумента `--output`: в нём хранятся словарь BoW, классификатор и настройки экстрактора. В режимах `test` и `predict` этот же путь передаётся через `--model`. Папки `models` и `results` программа создаёт при записи. Для MobileNetV2 приведены параметры модели, показавшей лучший результат.

```sh
python main.py train --data data/Dataset_640 --extractor sift --output models/sift.joblib
python main.py train --data data/Dataset_640 --extractor orb --output models/orb.joblib
python main.py train --data data/Dataset_640 --extractor resnet18 --output models/resnet18_layer4.joblib
python main.py train --data data/Dataset_640 --extractor mobilenetv2 --n-words 512 --C 10 --output models/mobilenetv2_svm_512.joblib
```

### Проверка на тестовой выборке

```sh
python main.py test --data data/Dataset_640 --model models/sift.joblib
python main.py test --data data/Dataset_640 --model models/orb.joblib
python main.py test --data data/Dataset_640 --model models/resnet18_layer4.joblib
python main.py test --data data/Dataset_640 --model models/mobilenetv2_svm_512.joblib
```

В выводе `accuracy` показывает долю верно распознанных снимков. В `macro F1` каждый класс имеет одинаковый вес, поэтому на эту метрику влияют и результаты редких классов.

### Предсказание для одной фотографии

```sh
python main.py predict --image examples/sample.jpg --model models/mobilenetv2_svm_512.joblib --save-plot results/prediction.png
```

Команда печатает метку класса и сохраняет снимок с гистограммой в `results/prediction.png`. Для своей фотографии замените путь после `--image`. Если убрать `--save-plot results/prediction.png`, рисунок откроется в окне.

Чтобы посмотреть по одному тестовому примеру каждого класса с правильной и предсказанной метками, соберите их на одном рисунке:

```sh
python demo.py --data data/Dataset_640 --model models/mobilenetv2_svm_512.joblib --output results/demo.png
```

## Результат

На 2354 тестовых фотографиях лучший результат показала **MobileNetV2 с линейным SVM — около 75% правильных ответов**. Для этой модели использовались признаки слоя `features[17]` и словарь из 512 визуальных слов.
